# AHB.db

The ahb.db file is the sqlite database file that contains the AHB data.

It gets created with the help of the python package [fundament](https://github.com/Hochfrequenz/xml-fundamend-python/).

[The script to create the database](https://github.com/Hochfrequenz/xml-migs-and-ahbs/blob/main/load_ahbs_into_sqlitedb.py) is stored next to the MIG and AHB XML files.
Cause the xml files are not public, this repository is private, so only members of the Hochfrequenz organization can access it.
