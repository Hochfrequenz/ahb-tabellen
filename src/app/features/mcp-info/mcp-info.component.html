AHB-Tabellen in Ihrem KI-Assistenten nutzen

Die AHB-Tabellen stehen zusätzlich als MCP-Server (Model Context Protocol) bereit. Damit können Sie die AHB-Daten direkt in Ihrem KI-Assistenten – zum Beispiel Claude, GitHub Copilot oder opencode – abfragen, ohne diese Website zu öffnen.

Was Sie damit tun können

  • einzelne AHBs zu einer Prüfidentifikator abrufen
  • über alle AHB-Zeilen hinweg suchen und filtern
  • zwei Formatversionen miteinander vergleichen (Diff und Änderungsübersicht)
  • verfügbare Formatversionen, Formate und Prüfidentifikatoren auflisten

Der Server ist schreibgeschützt – er liest ausschließlich Daten und verändert nichts.

Server-Adresse

Tragen Sie in Ihrem KI-Tool die folgende Adresse als Remote- bzw. HTTP-MCP-Server ein:

{{ mcpUrl }}

Beim ersten Verbinden öffnet sich gegebenenfalls ein Anmeldefenster – melden Sie sich dort mit Ihrem gewohnten Hochfrequenz-Konto an (dasselbe Login wie für diese Website).

Einrichtung in Ihrem KI-Tool

Die genauen Schritte unterscheiden sich je nach Tool. Folgen Sie der offiziellen Anleitung Ihres KI-Assistenten und tragen Sie dort die oben genannte Server-Adresse ein:

  • Claude (claude.ai & Claude Desktop – „Custom Connectors")
  • GitHub Copilot in VS Code
  • opencode
